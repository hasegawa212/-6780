# じぶんダッシュボード（自分専用・自動更新アプリ）

パスワードで守られた、**あなただけが見る**ミニ・ダッシュボードです。
天気・為替・暗号資産（BTC/ETH）を**自動で取得＆自動更新**します。

## 特長
- ✅ **今日やること**：チェックリストを作成。完了チェック・削除ができ、端末内に保存されるので次回も続きが見られます。
- 📝 **自由メモ**：なんでも書けるメモ欄。入力すると自動保存され、次回も続きが残ります。
- 🕐 **毎日ながめる定番**：大きな時計・今日の日付・曜日・**次の祝日まであと何日**を、入力なしで自動表示。
- 🌤 **天気は3日先まで**：今日・明日・明後日の天気と最高/最低気温。
- 🔒 **パスワード保護**：初回にパスワードを設定。合言葉を知っている人だけ開けます。
- 🔑 **APIキー不要**：無料の公開データ（Open-Meteo / Frankfurter / CoinGecko）を使用。
- 🔁 **自動更新**：画面を開いている間、10分ごとに自動でデータを取り直します。
- 📱 **スマホ対応**：iPhone / Android / PC どれでも見やすいデザイン。
- 🙈 **検索よけ**：`noindex` 設定で検索エンジンに載りません。

## 使い方（かんたん）
### A. パソコンで開くだけ
1. `personal-app/index.html` を**ダブルクリック**（ブラウザで開きます）。
2. 初回だけパスワードを決める → 次回からその入力で開けます。

### B. スマホからも見たい（クラウド公開）
このリポジトリはすでに Render 公開に対応しています。公開URLの末尾に
`/personal-app/` を付ければスマホからも開けます。手順は
`bc-pipeline/DEPLOY.md` の「クラウド公開（Render）」を参照してください。

## 表示する場所や項目を変えたい
`index.html` の上のほうにある `CONFIG` を書き換えるだけです。

```js
const CONFIG = {
  city: "東京",       // 表示する地名
  lat: 35.6895,       // 緯度（Googleマップで調べられます）
  lon: 139.6917,      // 経度
  refreshMinutes: 10, // 自動更新の間隔（分）
};
```

## パスワードについて（安全性）
- 入力したパスワードは**この端末の中だけ**にハッシュ化して保存され、
  リポジトリや外部サーバーには一切送られません。
- 表示している天気・為替などは公開情報のため、この保護は
  「うっかり他人に見られない」ためのライトなロックです。
  厳重な秘密情報の保管には使わないでください。
- パスワードを忘れたら、ログイン画面の「設定し直す」から作り直せます。
