# PRODUCT.md — 自動フォロー / さくら発信

## 目的
見込み客（特にバックれ・日程未定）を取りこぼさず、人手をかけずに再接触し、
話せたら会話AI「さくら」が一次対応、見込みが立てば担当者へ生転送する。

## ユーザー
- **ボス/管理者**（長谷川）: ON/OFF・自動運転・プレビュー・台帳確認。
- **担当者**: 生転送で鳴った通話を受けて商談。
- **お客様**: 発信を受ける側。安全ゲートで守る対象。

## 主要機能
1. **自動フォロー架電エンジン** (`tac/autofollow.py`): 台帳から次の1件を選び、ゲート通過なら発信。
   - 連続オート発信（`run_batch`）＋常駐スケジューラ（`tac/autofollow_scheduler.py`）。
2. **会話AIさくら** (`tac/realtime.py`): Twilio Media Streams ↔ OpenAI Realtime。
   低遅延・barge-in・日本語文字起こし・「恐れ入ります」で終わらせず会話を前へ。
3. **担当者への生転送** (`transfer_to_agent`): さくらが必要と判断したら担当携帯を鳴らす。
   不在/話中なら「改めて担当よりご連絡」で丁寧に終話。
4. **AMD（留守電判定）**: 機械なら即切断、人間なら会話継続。
5. **台帳/分類** (`tac/followup.py`): 記録を 再調整/日程返答待ち/不在/要確認/連絡停止 に分類。
   発信可=（再調整希望・日程返答待ち・不在）。
6. **ダッシュボード/モバイル** (`tac/autofollow_ui.py`, `tac/mobile_app.py`): 状態可視化と操作。

## 非目標（いまはやらない）
- 顧客データのリポジトリ保存。
- 承認なしの本番実発信・大量課金。
