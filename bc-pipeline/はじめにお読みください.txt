======================================================
 BC自動生成アプリ  かんたん起動ガイド
======================================================

このフォルダのファイルを丸ごとパソコンに置いてください。
（デスクトップなどに解凍でOK）

────────────────────────────────
■ Mac の人
────────────────────────────────
1) フォルダ内の
     「BC自動生成を起動.command」
   をダブルクリック。
   ※初回だけ「開けません」と出たら、右クリック→「開く」→「開く」。

2) 黒い画面が出て、初回は数分セットアップ（自動）。
   途中で
     ・APIキー（sk-ant-… ）→ あれば貼り付けてEnter／無ければ空Enter
     ・ログインID（例: hikaru）→ 入力してEnter
     ・パスワード → 2回入力
   を聞かれます。

3) 数秒でブラウザ（Safari）が自動で開きます。
   開かなければ、ブラウザで  http://localhost:8800/  を開いてください。

4) 上で決めた ID／パスワード でログイン → PDFを入れて読み取り。

────────────────────────────────
■ Windows の人
────────────────────────────────
1) フォルダ内の
     「BC自動生成を起動.bat」
   をダブルクリック。
   ※「WindowsによってPCが保護されました」と出たら
     「詳細情報」→「実行」を押してください。

2) 黒い画面が出て、初回は数分セットアップ（自動）。
   聞かれる内容は Mac と同じ（APIキー→ID→パスワード）。
   ※もし「Python が見つかりません」と出たら、開いたページから
     Python をインストール（「Add Python to PATH」にチェック）→
     もう一度 .bat をダブルクリック。

3) 数秒でブラウザが自動で開きます。
   開かなければ  http://localhost:8800/  を開いてください。

4) 決めた ID／パスワード でログイン → PDFを入れて読み取り。

────────────────────────────────
■ 準備しておくもの
────────────────────────────────
・Anthropic の APIキー（sk-ant-… ）
   → 自動読み取りに使います。無くても手入力でExcelは作れます。
   → https://console.anthropic.com/ で発行できます。
・様式のExcel（36-1 / 37-1 / 38-1 など）
   → 会社で使っている様式ブックを、指示された場所に置いてください。
     （詳しくは README.md / DEPLOY.md を参照）

────────────────────────────────
■ 止め方
────────────────────────────────
黒い画面のウィンドウを閉じればアプリも止まります。

────────────────────────────────
■ うまくいかない時
────────────────────────────────
・黒い画面に出た文章を、そのまま写真に撮って共有してください。
・「ブラウザが真っ白」→ 10〜20秒待ってから再読み込み。
・ログインできない → IDとパスワードは、起動時に自分で決めたものです。
