# ADR-0006: 本番の安全装置（緊急停止・一時停止・同時通話数・予算）

- Status: Accepted
- Date: 2026-10-04

## Context
発信システムは、不具合や設定ミスがあると「短時間に大量の迷惑電話」や「費用の暴走」を起こしうる。
現行 TAC にあるのは 1 日上限（既定 OFF）だけで、止めるにはサーバーを止めるしかない。

## Decision
発信ガード（`evaluateCallPolicy`）の **抑止より前** に、次の安全装置を評価する。どれか1つでも該当すれば発信しない。

| 装置 | 範囲 | 拒否コード |
|---|---|---|
| 全発信停止（STOP ALL OUTBOUND CALLS） | システム全体 | `OUTBOUND_STOPPED` |
| 組織の一時停止 | 組織 | `ORGANIZATION_PAUSED` |
| キャンペーンの一時停止 | キャンペーン | `CAMPAIGN_PAUSED` |
| 同時通話数の上限 | 組織 | `CONCURRENCY_LIMIT_REACHED` |
| 予算の上限（電話・AI の費用） | 組織・キャンペーン | `BUDGET_EXCEEDED` |

- 停止系（上の3つ）は **抑止よりも先** に評価する。止めているときに抑止の確認で外部に問い合わせる必要がないため。
  拒否理由の一覧には、抑止も含めて該当するものをすべて返す。
- 停止・再開の操作は Owner / Admin だけができ、監査ログに残す（Phase 5 / 16）。
- 1通話の最長時間・サーキットブレーカー（プロバイダのエラー率）・費用のサーキットブレーカーは、通話中・worker 側の仕組みとして Phase 7 / 11 / 12 で実装する。

## Consequences
- 停止は「発信を始めない」ことを保証する。すでに進行中の通話を切るのは別の操作（`endCall`）。
- 停止中の発信要求は `blocked` として記録されるので、停止中に誰が掛けようとしたかも分かる。
